# Minesweeper

## How to Play
To start the game, select a tile and "uncover" it. The first tile that is uncovered will always be safe (not a mine) An uncovered tile will either be a mine, space, or number. If a mine is uncovered, you lose. If a space is uncovered, all tiles around the space is also uncovered. A number tile signifies the number of mines surrounding (both orthogonally and diagonally) that number tile. Players may choose to flag a tile as a mine. It serves no purpose besides helping the player keep track of which tiles they believe contains a mine. The game ends when the player uncovers a mine or all non-mine tiles are uncovered.
